# Groyyo

> Groyyo is a Gurugram, India based B2B manufacturing and supply-chain company for the fashion, apparel and lifestyle industry, founded in July 2021 by Subin Mitra and Pratik Tiwari. It matches global brands with a vetted network of small and mid-sized Asian factories and gives those factories production software — sales-order management, bill-of-materials creation, production tracking, quality control and business reporting — delivered as mobile apps and an internal factory ERP.

## What an agent can and cannot do here

- **There is no public API.** As of 2026-08-22 Groyyo publishes no developer portal, no API reference, and no machine-readable contract (OpenAPI, AsyncAPI, GraphQL SDL, MCP tools/list, gRPC/Protobuf or WSDL) on any host it controls. Probes of developer.groyyo.com, docs.groyyo.com and api.groyyo.com all return 404.
- **There is no agent surface.** No MCP server, no A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json, no /.well-known/api-catalog, no OAuth or OIDC discovery document. All returned 404 against a host that also returns a true 404 for a bogus control path.
- **Software is delivered as apps, not endpoints.** Factory-side functionality ships as the Groyyo + Android app (com.groyyo.plus) and the Groyyo mobile app; app.groyyo.com is a deep-link redirect into the installed app, not a web API.
- **Engagement is sales-led.** Brands and factories start at the RFQ form or the get-in-touch form; suppliers onboard through the KYC digitisation flow. There is no self-serve signup, no published pricing and no API keys to obtain.
